# Mars Surface Feature Classifier

## Overview
The Mars Surface Feature Classifier is a deep learning model developed to detect and classify various Martian surface structures using images from NASA's HiRISE dataset. The model categorizes images into seven classes: crater, dark dune, slope streak, bright dune, impact ejecta, swiss cheese, and spider.

## Features
- Seven-class classification model for Martian surface features
- Automatic class label assignment for uploaded images
- Achieved approximately **79%** classification accuracy
- Utilizes advanced image processing techniques for enhanced image quality

## Technologies Used
- **Programming Language:** Python
- **Frameworks/Libraries:** TensorFlow, OpenCV, PIL
- **Model Architecture:** Convolutional Neural Networks (CNN)
